# Deploy to Railway + Android Play Store

This guide covers deploying the Next.js app to Railway and publishing it on the Google Play Store as a Trusted Web Activity (TWA).

## Prerequisites

- A [Railway](https://railway.app) account (free tier available).
- A [Google Play Developer account](https://play.google.com/console/signup) ($25 one-time fee).
- A custom domain you control (required for TWA verification; `*.railway.app` subdomains cannot be verified).
- Node.js 20+ and npm.
- Java 17+ and Android SDK for building the Android app (or use Bubblewrap CLI).

---

## 1. Deploy to Railway

### 1.1 Push code to GitHub

Railway deploys from a Git repository. Push this project to a GitHub repo if you haven't already:

```bash
git init
git add .
git commit -m "Prepare Railway + Play Store deployment"
git branch -M main
git remote add origin https://github.com/YOUR_USERNAME/YOUR_REPO.git
git push -u origin main
```

### 1.2 Create project on Railway

1. Log in to [Railway](https://railway.app).
2. Click **New Project** → **Deploy from GitHub repo**.
3. Select your repository.
4. Railway will detect the `railway.toml` config and use Nixpacks to build and start the app.

### 1.3 Set environment variables

In the Railway project dashboard, go to **Variables** and add:

- `DEEPSEEK_API_KEY` — your DeepSeek API key. If you don't have one, leave it unset and the app falls back to the deterministic rule-based latticework.

> **Security:** Never commit API keys. The existing `.env.local` is ignored by Git.

### 1.4 Add a custom domain

1. In Railway, go to your service's **Settings** → **Domains**.
2. Click **Custom Domain** and follow the DNS instructions.
3. Wait for DNS to propagate, then note your domain (e.g. `app.yourdomain.com`).

### 1.5 Verify deployment

Open your custom domain in a browser. The app should load, and the following URLs should be accessible:

- `https://app.yourdomain.com/manifest.json`
- `https://app.yourdomain.com/.well-known/assetlinks.json`

## 2. Build the Android app (Trusted Web Activity)

We use [Bubblewrap](https://github.com/GoogleChromeLabs/bubblewrap) to generate a minimal Android wrapper that opens the Railway-hosted app in a trusted Chrome Custom Tab.

### 2.1 Install Bubblewrap

```bash
npm install -g @bubblewrap/cli
```

### 2.2 Update the TWA manifest

Edit `twa-manifest.json` in this repo:

- Replace `REPLACE_WITH_YOUR_RAILWAY_CUSTOM_DOMAIN` with your custom domain (e.g. `app.yourdomain.com`).
- The repo already includes placeholder `public/icon-192.png` and `public/icon-512.png`. Replace them with your branded icons before publishing.

### 2.3 Generate the Android project

```bash
bubblewrap build --manifest twa-manifest.json
```

This creates:

- `app-release-signed.apk` (for testing)
- `app-release-bundle.aab` (for Play Store)
- Your app's signing certificate info

### 2.4 Update Digital Asset Links

After the first build, Bubblewrap prints your SHA-256 fingerprint. Update `public/.well-known/assetlinks.json`:

```json
[
  {
    "relation": ["delegate_permission/common.handle_all_urls"],
    "target": {
      "namespace": "android_app",
      "package_name": "com.optionpricing.app",
      "sha256_cert_fingerprints": [
        "AA:BB:CC:...:FF"
      ]
    }
  }
]
```

Replace `AA:BB:CC:...:FF` with your actual SHA-256 fingerprint. Redeploy to Railway so the file is served at:

```
https://app.yourdomain.com/.well-known/assetlinks.json
```

### 2.5 Test the Android app

Install the generated APK on an Android device and verify it opens your Railway app in full-screen without the browser address bar.

---

## 3. Publish to Google Play

1. Open [Google Play Console](https://play.google.com/console/).
2. Create a new app and fill in store listing details (title, description, screenshots, etc.).
3. Go to **Production** → **Create new release**.
4. Upload `app-release-bundle.aab` generated by Bubblewrap.
5. Complete the content rating questionnaire, pricing, and distribution settings.
6. Submit for review.

## Recommended next steps

- Replace placeholder `public/icon-192.png` and `public/icon-512.png` with branded icons and update `manifest.json` and `twa-manifest.json`.
- Add a 1024x500 feature graphic and 512x512 high-res icon for the Play Store listing.
- Enable Play App Signing in the Play Console and use the provided fingerprints for `assetlinks.json`.
